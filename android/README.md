# Wens AI Android

تطبيق Android WebView يفتح النسخة المستضافة من ونس على Cloudflare Worker. يستخدم صوت Android المحلي أولًا عند توفر حزمة عربية/مصرية، ثم يرجع لصوت المتصفح. اللهجة والصوت المتاحان يعتمدان على محرك تحويل النص إلى كلام المثبت على الجهاز.

## إصدار التجربة

- `applicationId`: `com.wens.ai`
- `versionCode`: `5`
- `versionName`: `1.4`
- `minSdk`: 23
- `targetSdk`: 35
- لا توجد مفاتيح API داخل APK.
- الصوت محلي على الجهاز، أما الذكاء الاصطناعي فيعتمد على حصة Cloudflare Workers AI المتاحة للخادم.

## بناء APK

يمكن بناء نسخة Debug من Android Studio باستخدام JDK 17 وAndroid SDK 35، أو عبر GitHub Actions من ملف `android-apk.yml`. يرفع Workflow ملفًا تجريبيًا باسم `wens-android-apk` لمدة 30 يومًا.

## فحص الهاتف

1. ثبّت APK على Android 13 أو أحدث.
2. سجّل الدخول بحساب اختبار أو الحساب المعتاد.
3. شغّل زر «اسمع رد ونس» واستمع حتى نهاية الرد.
4. جرّب الميكروفون ووافق على الإذن عند الطلب، ثم ارفضه مرة ثانية للتأكد من رسالة الرفض.
5. جرّب تدوير الشاشة والعودة للتطبيق ثم زر الرجوع.
6. لا تعتبر الصوت مصريًا لمجرد ظهور إعداد ar-EG؛ اختبر النطق المسموع على الهاتف نفسه.

هذا APK تجريبي Debug وليس إصدار متجر موقّعًا بمفتاح Release.
