# ونس AI — مشروع تطوير أندرويد وويب

ونس AI تطبيق ويب تقدمي عربي، مع حسابات وجلسات محفوظة في D1، وكيل لتنفيذ أدوات ومشاريع ويب، بحث عام مجاني محدود المصادر، واستخراج محلي مجاني لنصوص بعض المستندات. الصوت الطبيعي عبر OpenAI Realtime ليس جزءًا من الوضع المجاني؛ الافتراضي هو صوت الجهاز المتاح. مكالمات الفيديو الحية غير منفذة في الإصدار الحالي.

## الحالة التقنية

| الجزء | حالة الكود | ما يلزم لتشغيله فعليًا |
|---|---|---|
| تطبيق أندرويد APK | مشروع Android موجود + GitHub Actions للبناء | نجاح مهمة Android APK لتنزيل ملف APK |
| تسجيل الدخول | تسجيل/دخول/خروج وجلسة Cookie آمنة | ربط D1 وتطبيق migration |
| قاعدة البيانات | مخطط D1 للمستخدمين والجلسات والرسائل | إنشاء D1 وربطه باسم DB |
| النطق الصوتي المجاني | Web Speech وصوت الجهاز مع تفضيل ar-EG | يختلف حسب الأصوات المثبتة في هاتف المستخدم؛ لا نضمن صوتًا مصريًا أنثويًا في كل جهاز |
| OpenAI Realtime | مسار اختياري موجود في الكود | يتطلب API مدفوعًا؛ لا يُستخدم كاعتماد افتراضي في النسخة المجانية |
| قراءة المستندات | استخراج محلي من PDF نصي وDOCX وXLSX وPPTX | OCR للملفات المصوّرة غير متاح، والصيغ القديمة تحتاج تحويلًا |
| ذاكرة المستخدم | ذاكرة اختيارية خاصة لكل حساب مع حفظ/عرض/حذف | غير حساسة فقط وبعد طلب صريح من المستخدم |
| PWA | Manifest وService Worker منشوران | يلزم اختبار التثبيت والعمل دون اتصال على Android وiOS |
| الذكاء الاصطناعي | Cloudflare Workers AI عبر binding باسم AI | حصة مجانية يومية وحدود النموذج |
| البحث في المواقع الخارجية | بحث تلقائي قبل الأسئلة الواقعية والمعلوماتية والبيانات المتغيرة | عرض حالة البحث والمصادر الخارجية داخل نفس المحادثة؛ تُرفض الأرقام المتغيرة غير المثبتة |

لا تعتبر الميزة متاحة لمجرد وجود كودها أو Binding. افحص `GET /api/health` و`GET /api/admin/status` بعد النشر؛ وجود مفتاح الصوت أو ربط المتصفح لا يثبت نجاح جلسة Realtime أو تصفح موقع.

## البحث الخارجي داخل المحادثة

تقوم واجهة الدردشة بإظهار حالة انتظار أثناء عمل ونس، ثم تعرض سجل أدوات البحث والتنفيذ وروابط المواقع التي استُخدمت داخل رد ونس نفسه. يجري الخادم بحثًا خارجيًا قبل الأسئلة الواقعية والمعلوماتية والبيانات المتغيرة، ويمرر نتائج المواقع إلى النموذج قبل صياغة الإجابة. أسعار الذهب في مصر لا تُعرض إلا عند وجود مصدرين مستقلين يدعمان السعر بالجنيه المصري وتوقيت التحديث؛ وإلا توضح ونس أن السعر لم يُتحقق منه. هذا الإصدار يعرض حالة التنفيذ والنتائج بعد رجوع الطلب، وليس بثًّا حيًا لكل كلمة أو لكل نتيجة أثناء تحميلها.

## ملفات الواجهة المنشورة

Cloudflare Workers Assets يخدم المجلد `public/` فقط طبقًا لإعداد `wrangler.jsonc`. لذلك يجب أن تكون كل صفحات وملفات الواجهة العامة داخل هذا المجلد. صفحة الإعدادات `/owner-panel` وملفاتها موجودة داخله أيضًا. عند تعديل `index.html` أو `app.js` أو `style.css` في جذر المشروع، حدّث النسخة المقابلة في `public/`؛ فحص الجودة يقارن النسختين.

لوحة `/owner-panel` محمية على الخادم بحساب المالك وكلمة مرور مدير مستقلة محفوظة hash في D1، وتُفتح من التطبيق بالضغط على صورة ونس خمس مرات خلال 3 ثوانٍ. جلسة المدير منفصلة ومؤقتة. إعدادات الهوية والصوت ورسائل البداية مركزية في D1 وتُحمّل للأجهزة من الخادم. اللوحة لا تكشف مفاتيح API؛ إدارة الأسرار تتم من Cloudflare Secrets.


## قراءة الملفات مجانًا

يعالج الخادم محليًا ملفات PDF التي تحتوي على طبقة نصية، وDOCX وXLSX وPPTX. لا يرسل محتوى هذه الصيغ إلى OpenAI File API، ولا يحفظ الملف الخام في قاعدة بيانات ونس. الحد 8 ميجابايت لكل ملف، و4 ميجابايت للمحتوى بعد فك الضغط. لا يتوفر OCR للملفات الممسوحة ضوئيًا أو تحويل للصيغ القديمة DOC/XLS/PPT؛ يوضح ونس ذلك بدل ادعاء قراءة الملف. يجب مقارنة مقتطف الاستخراج بالأصل قبل الاعتماد على دقة الأرقام والجداول.

## ذاكرة المستخدم

الذاكرة اختيارية على مستوى الحساب، والوكيل لا يحفظ معلومة إلا بطلب صريح. توجد أدوات لحفظ وعرض وحذف التفضيلات والاهتمامات وتفاصيل المشروعات غير الحساسة. تمنع السياسة كلمات المرور والمفاتيح وبيانات الدفع والبيانات الصحية والدينية والسياسية والجنسية وبيانات الهوية والعناوين الخاصة. الحد الحالي 30 معلومة لكل حساب.

## التخزين المؤقت وPWA

يسجل التطبيق Service Worker عبر HTTPS، ويستخدم Cache للأصول العامة فقط. تُستثنى جميع مسارات API حتى لا تُخزّن الردود الخاصة أو إعدادات الحساب. التخزين دون اتصال لا يعني إمكانية استخدام الدردشة أو قاعدة البيانات دون إنترنت؛ يوفر فقط الأصول الثابتة وواجهة احتياطية.

## إعداد قاعدة البيانات D1 (لنسخة جديدة من المشروع)

قاعدة الإنتاج لهذا المشروع أُنشئت بالفعل باسم `wens-ai-db` وربطها موجود في `wrangler.jsonc`. عند إنشاء نسخة مستقلة من المستودع في حساب Cloudflare آخر، أنشئ قاعدة D1 جديدة باسم مناسب:

```bash
npx wrangler d1 create wens-ai-db
```

خذ `database_id` الذي يرجع من Cloudflare، ثم استبدل ربط `DB` في `wrangler.jsonc` بالمعرّف الجديد:

```jsonc
"d1_databases": [
  {
    "binding": "DB",
    "database_name": "wens-ai-db",
    "database_id": "ضع-DATABASE-ID-الحقيقي-هنا",
    "migrations_dir": "migrations"
  }
]
```

طبّق الجداول على قاعدة الإنتاج:

```bash
npx wrangler d1 migrations apply wens-ai-db --remote
```

**لا تنشر إعداد D1 وفيه قيمة placeholder.** لا ترفع أي بيانات مستخدمين أو كلمات مرور إلى GitHub.

## إعدادات الإدارة

لا تحتاج لوحة الإدارة إلى أسرار إضافية. صلاحية المدير مرتبطة بحساب المالك الموجود مسبقًا في قاعدة D1، وتُنشأ له جلسة مؤقتة مدتها أربع ساعات بعد التحقق من كلمة المرور. لا تضع كلمات المرور في ملفات المستودع.

- `GET /api/admin/session` — فحص جلسة المدير.
- `POST /api/admin/login` — دخول المدير بالبريد وكلمة مرور المدير المستقلة.
- `POST /api/admin/setup` — إنشاء/إعادة إعداد كلمة مرور المدير بعد التحقق من جلسة المالك وكلمة مرور حساب ونس.
- `POST /api/admin/logout` — إنهاء جلسة المدير.
- `GET /api/admin/status` — حالة Workers AI وقاعدة البيانات.
- `POST /api/admin/test-ai` — اختبار نموذج Workers AI.
- `GET /api/settings` — تحميل إعدادات التطبيق العامة من D1.
- `GET /api/admin/settings` و`PUT /api/admin/settings` — قراءة وحفظ الإعدادات المركزية بعد التحقق من حساب المالك.

## بناء APK أندرويد

يوجد مشروع أندرويد داخل `android/` وسير عمل GitHub Actions داخل `.github/workflows/android-apk.yml`. عند دفع تحديثات في مجلد `android/` يبدأ بناء APK تلقائيًا، ويمكن تشغيله يدويًا من تبويب Actions.

بعد نجاح المهمة نزّل Artifact باسم `wens-android-apk`، ثم استخرج `app-debug.apk` وثبّته للاختبار. هذا Debug APK للتجربة الداخلية وليس إصدار متجر موقّعًا بمفتاح نشر نهائي.

## فحوص ما قبل النشر

1. افحص حالة Workers AI وD1 وRealtime وBrowser كلٌّ على حدة؛ وجود الربط وحده ليس اختبار تشغيل.
2. أنشئ حسابًا تجريبيًا، سجّل الخروج ثم الدخول، وافتح المحادثة من متصفح آخر للتأكد من حفظها.
3. اختبر صوت الجهاز من الهاتف: اختيار صوت عربي متاح، سماع الرد، إعادة التشغيل، منع autoplay، ورفض إذن الميكروفون. لا تعتبر Realtime خدمة مجانية.
4. اختبر ملفات PDF النصية وDOCX وXLSX وPPTX حقيقية، وملف PDF ممسوح ضوئيًا، والحدود وأنواع الملفات غير المدعومة.
5. اختبر أدوات الوكيل والذاكرة بنتيجة نجاح وفشل ومهلة زمنية، ثم تحقق من حفظ الإعدادات وظهورها على جهاز آخر.
6. لا تنشر نسخة عامة قبل سياسة خصوصية، شروط استخدام، حماية إساءة الاستخدام، ومراجعة إعدادات الاحتفاظ بالرسائل.
