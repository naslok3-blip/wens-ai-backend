# اختبارات ونس على الهاتف قبل اعتماد الإصدار

هذه قائمة قبول يدوية. فحوص GitHub لا تثبت أن الصوت مسموع من الهاتف أو أن المستند الحقيقي قُرئ بدقة.

## 1. الدخول وفتح لوحة الإدارة
1. افتح نسخة ونس المنشورة وسجّل الدخول بحساب المالك المعتاد.
2. اضغط على صورة ونس خمس مرات لفتح لوحة الإدارة داخل التطبيق نفسه.
3. سجّل الدخول بكلمة مرور المدير المستقلة. لا تشارك كلمة المرور أو مفاتيح الخدمات.

## 2. مركز التشغيل
- افتح «مركز التشغيل» ثم اضغط «تحديث التشخيص والأرقام».
- افحص اتصال D1 ووجود الجداول الأساسية.
- الأرقام المعروضة مجاميع إحصائية فقط؛ لا تعرض أسماء المستخدمين أو محتوى الرسائل.

## 3. اختبار الوكيل
- افتح «الوكيل والأدوات» واضغط «اختبار الوكيل الآن».
- معيار نجاح هذا الاختبار: ظهور خطوة «إجراء حساب — تم» ونتيجة 19 × 23 = 437.
- يختبر هذا المسار النموذج وأداة الحساب؛ ولا يثبت نجاح جميع عمليات المتصفح أو المواقع الخارجية.

## 4. اختبار ملف حقيقي من الهاتف
- افتح «اختبار الملفات»، واختر ملفًا تجريبيًا غير حساس بصيغة PDF نصي أو DOCX أو XLSX أو PPTX.
- فعّل الموافقة ثم اضغط «اختبار قراءة الملف»؛ الاستخراج محلي على الخادم ولا يستخدم OpenAI File API.
- قارن مقتطف النص المستخرج بالعناوين والأرقام والجداول في الملف الأصلي.
- اختبر PDF مصوّرًا؛ يجب أن يذكر ونس أن OCR غير متاح، لا أن يخترع نصًا.
- الحد 8 ميجابايت للملف و4 ميجابايت للمحتوى المستخرج. صيغ DOC/XLS/PPT القديمة تحتاج تحويلًا.

## 5. اختبار الصوت الطبيعي
- في APK Android 1.4، يفترض أن يستدعي التطبيق محرك Android TTS المحلي أولًا مع اختيار الصوت المصري إن كان مثبتًا، ثم يستخدم صوت المتصفح عند عدم جاهزية المحرك.
- اسم المحرك أو اللغة المعروضة لا يثبت أن النطق مصري أو أن الصوت أنثوي؛ تحقق بالسماع المباشر.
- افتح «الصوت والمساعدة» واضغط «بدء اختبار صوت ونس».
- ارجع إلى مشغل الصوت الظاهر في صفحة التطبيق، واضغط تشغيل إذا لم يبدأ تلقائيًا.
- استمع إلى العينة كاملة. اضغط «تأكيد أنني سمعت الصوت» فقط بعد سماعها فعليًا.
- إذا ظهر المشغل دون صوت، لا تضغط التأكيد؛ احتفظ برسالة الخطأ كما ظهرت.

## قرار اعتماد الإصدار
لا تعتمد النسخة النهائية حتى تنجح الاختبارات الثلاثة على الهاتف نفسه: سماع الصوت، تنفيذ الوكيل لأداة الحساب، وقراءة ملف حقيقي مع مراجعة المقتطف مقابل الأصل. وجود مفتاح API أو ربط خدمة لا يكفي وحده لإعلان الميزة جاهزة.

## الذاكرة والخصوصية

- اطلب صراحةً من ونس حفظ تفضيل غير حساس، ثم اطلب عرض الذاكرة والتأكد من ظهوره.
- اطلب حذف المعلومة نفسها، ثم اعرض الذاكرة مرة أخرى للتأكد من الحذف.
- تأكد من رفض حفظ كلمات المرور والمفاتيح وبيانات الدفع والمعلومات الصحية أو السياسية أو الدينية أو الجنسية أو الهوية والعناوين الخاصة.

## PWA والاتصال

- افتح الموقع عبر HTTPS وتحقق من تسجيل Service Worker من المتصفح.
- جرّب فتح الواجهة بعد زيارة سابقة مع قطع الاتصال؛ يجب أن تظهر الأصول الثابتة، لكن API والدردشة لا تعمل دون إنترنت.
- تحقق من أن مسارات API لا تُخزّن في Cache Storage.
