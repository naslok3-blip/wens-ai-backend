# ملف التسليم الفني — Wens AI

## 1. الهدف من هذه النسخة
هذه نسخة مرشحة للمراجعة الهندسية، وليست إعلانًا بأن كل ميزات المنتج اكتملت. يصف المستند ما هو موجود في الكود، وحدود التشغيل المجاني، والاختبارات الآلية، وما لا يزال يحتاج قبولًا يدويًا على أجهزة حقيقية.

## 2. البنية الحالية
- واجهة ويب تقدمية عربية RTL داخل مجلد public.
- Cloudflare Worker يوفّر API للمحادثة والوكيل والمصادقة والإدارة.
- Cloudflare D1 للحسابات والجلسات والرسائل والمهام والإعدادات وبيانات الذاكرة والإشعارات.
- Cloudflare Workers AI للاستدلال المجاني ضمن الحصة اليومية المتاحة للحساب.
- Cloudflare Browser Run للتصفح المصرّح به ضمن حدود الخدمة.
- مشروع Android WebView يفتح التطبيق المستضاف؛ ملف APK التجريبي يُبنى عبر GitHub Actions عند تشغيل مسار البناء.

## 3. التغييرات المضافة في دورة المراجعة
### بحث الويب المجاني
- استبدال الاعتماد الإجباري على فتح صفحات Google/Bing/DuckDuckGo داخل Browser Run بمصادر عامة مجانية: Google News RSS وDuckDuckGo Instant Answers وWikipedia.
- عرض روابط المصادر وحالة الفشل بدل اختلاق نتائج.
- هذا ليس محرك بحث شاملًا لكل صفحات الإنترنت. مصادر الأخبار والمعلومات الموسوعية لا تكفي لكل سؤال؛ على الوكيل الاعتراف بنقص المصدر.

### الوقت والتاريخ
- حساب الوقت والتاريخ داخل الخادم باستخدام المنطقة الزمنية IANA: Africa/Cairo.
- إجابات الوقت والتاريخ لا تعتمد على ذاكرة النموذج أو توقيت UTC المعروض على أنه توقيت محلي.
- اختبارات رجعية لصيغ مصرية مثل «الساعة كام» و«النهاردة كام».

### الملفات دون خدمة مدفوعة
- إضافة document-utils.mjs لاستخراج نص من PDF ذي طبقة نصية، وDOCX وXLSX وPPTX.
- استخراج ZIP/XML محليًا في Worker ضمن حدود الحجم وفك الضغط.
- يمر النص المستخرج إلى Workers AI ليقوم بالفهم والإجابة.
- لا يوجد OCR للـPDF الممسوح ضوئيًا في هذا الوضع.
- صيغ Office القديمة DOC وXLS وPPT لا تُقرأ مباشرة؛ يلزم تحويلها إلى DOCX/XLSX/PPTX.
- ملفات كبيرة أو مضغوطة بصورة غير طبيعية أو محمية بكلمة مرور تُرفض بوضوح.
- قراءة الجداول تحتاج مقارنة عينة الاستخراج بالأصل قبل الاعتماد على القيم والأرقام.

### الذاكرة الخاصة
- أدوات save_memory وlist_memories وdelete_memory.
- لا تحفظ ونس أي معلومة إلا إذا طلب المستخدم صراحةً تذكّرها أو حفظها.
- الذاكرة مرتبطة بمعرّف المستخدم في D1، وتُحقن في سياق حسابه فقط.
- الحد الحالي 30 معلومة، حتى 500 حرف للمعلومة.
- تمنع سياسة الذاكرة حفظ كلمات المرور ومفاتيح API ورموز التحقق وبيانات الدفع والمعلومات الصحية والدينية والسياسية والجنسية والهوية والعناوين الخاصة.
- توجد اختبارات رجعية لسياسة الخصوصية. الاختبار الوظيفي على حساب مستخدم حقيقي ما زال مطلوبًا.

### مركز الإشعارات داخل التطبيق
- إضافة جدول user_notifications مع ملكية لكل مستخدم.
- إشعار داخل الدردشة عند حفظ مهمة أو إكمالها، سواء عبر الوكيل أو قائمة المهام.
- إمكانية تعليم إشعار مفرد أو جميع الإشعارات كمقروءة.
- لا توجد إشعارات Push للهاتف خارج التطبيق، ولا جدولة خلفية أو تنبيه عند إغلاق الموقع في هذه النسخة.

### PWA وتخزين الأصول
- تسجيل Service Worker من واجهة التطبيق.
- Service Worker منشور داخل public ويخزن الأصول العامة فقط.
- مسارات /api/ مستثناة من التخزين المؤقت حتى لا تُخزن المحادثات أو بيانات الحساب الخاصة في Cache Storage.
- العمل دون اتصال يتيح واجهة/أصولًا ثابتة سبق تحميلها فقط؛ لا يمكن إجراء محادثة أو تحديث حساب دون اتصال.
- جرى تحديث manifest ومزامنة ملفات Worker المضمّنة مع نسخ public.

### لوحة المالك والقدرات القائمة
- لوحة المالك داخل عنوان ونس نفسه، ومدخلها بالضغط خمس مرات على شعار ونس.
- الجلسة الإدارية منفصلة ومحمية خادميًا، وإعدادات الهوية محفوظة على D1.
- إحصاءات الحسابات والجلسات والرسائل ومحاولات الدخول موجودة في لوحة المالك.
- ملفات الإدارة المضمّنة وملفات public وحّدت خلال التحديث؛ يجب إعادة فحصها بعد كل تغيير.
- إنشاء تطبيقات/ألعاب ويب وحفظها ومعاينتها وتنزيلها وتسجيل نسخ التعديلات موجود في الكود، لكنه لا ينشئ APK أصليًا ولا ينشر موقعًا عامًا تلقائيًا.
- مسارات إنشاء الصور وتعديلها موجودة في الوكيل؛ يلزم اختبار إنتاجي للقدرة والحصة وجودة الصورة.

## 4. حدود الخدمات المجانية
- Workers AI المجاني له حصة يومية محدودة. لا يعني ذلك استخدامًا غير محدود؛ قد تتوقف الطلبات عند بلوغ الحصة.
- Browser Run له حد استخدام مجاني يومي.
- البحث المجاني المضاف محدود بالمصادر العامة المتاحة وليس بديلًا كاملًا عن محرك بحث مدفوع.
- الصوت الافتراضي محلي عبر أصوات الجهاز/المتصفح. جودة اللهجة المصرية تختلف حسب حزمة الأصوات المثبتة.
- OpenAI Realtime موجود كمسار اختياري لكنه يتطلب مفتاحًا وصلاحية/رصيدًا؛ لا يُعتبر جزءًا من التشغيل المجاني ولا ينبغي تفعيله دون موافقة المستخدم.
- لا توجد مكالمات فيديو حية متكاملة أو شخصية مرئية متزامنة في هذه النسخة.

## 5. ميزات ما زالت غير مكتملة أو لم تثبت ميدانيًا
1. **صوت مصري طبيعي مضمون:** لا يمكن ضمان صوت أنثوي مصري في كل هاتف؛ الاختبار يجب أن يكون بسماع حقيقي، لا بمجرد ضبط ar-EG.
2. **مكالمات الفيديو:** غير منفذة كاتصال حي بين المستخدم ووكيل مرئي.
3. **OCR:** لا يوجد OCR للصور/الصفحات الممسوحة داخل PDF.
4. **مكتبة ملفات عامة للمستخدم:** المرفقات تُعالج في طلبها؛ توجد مكتبة مشاريع ويب محفوظة، لكن لا توجد مكتبة مستندات/صور شخصية شاملة.
5. **تقييم الردود:** لا توجد واجهة تصويت مفيدة/غير مفيدة وسجل مراجعة للردود بعد.
6. **إشعارات الهاتف الخارجية:** الموجود مركز إشعارات داخل التطبيق فقط، وليس Web Push.
7. **شخصية قابلة للتخصيص لكل مستخدم:** الذاكرة تحفظ تفضيلات غير حساسة وتُستخدم في السياق، لكن لا توجد شاشة إعداد شخصية متكاملة ومفصّلة لكل حساب.
8. **اختبارات المستخدم المالك:** لم تُنفّذ من هاتف المالك في هذه البيئة، ولا أستطيع ادعاء نجاح تسجيل دخوله أو رفع صورته أو استعادتها.
9. **قبول ملفات فعلية من هاتف المستخدم:** اختبارات الوحدات تثبت تنسيقات محددة؛ يلزم مقارنة عدة ملفات فعلية عربية وخاصة بالجداول.
10. **APK إصدار نهائي:** يوجد مسار Debug APK للتجربة؛ لا يوجد ملف متجر موقّع بمفتاح إصدار إنتاجي.
11. **اعتماد iPhone:** يلزم اختبار Safari وPWA على جهاز iOS؛ اختبارات GitHub لا تثبت ذلك.
12. **الظهور في Google:** توجد بيانات SEO وsitemap/robots، لكن فهرسة Google الفعلية لا تُثبت من الكود وحده.

## 7. ضمانات التغيير أثناء هذه الدورة
- لم تُغيّر كلمات مرور المستخدم أو المدير.
- لم تُعدّل مفاتيح API أو Secrets أو إعدادات دفع.
- لم تُحذف جداول أو حسابات أو محادثات قائمة.

- أي اختبار يعتمد على ملف حقيقي ينبغي أن يستخدم ملفًا تجريبيًا غير حساس.

## 8. قرار الإطلاق
لا يُعلن ونس «مكتملًا احترافيًا» قبل إغلاق عناصر مصفوفة الاختبار التي تتطلب هاتفًا وحساب مالك، وبالأخص الصوت والملفات ولوحة الإدارة. نتيجة البناء الآلي وحدها لا تثبت جودة كل ميزة على الهاتف.
